Operating Rules

  • Single Controller: Orchestrator is the only controller. Infra is a delegated worker, not a peer.
  • Shared Specialists: Analyst, Writer, Marketer, Coder are ONE instance each. Infra requests them through Orchestrator — never spawns duplicates.
  • No Duplicate Tasks: All shared tasks go through Orchestrator's single instance of each specialist.
  • Infra's Workers: Executor, Sentinel, Web, Publisher, Reviewer are profiles under Infra's coordination.
  • Shared Pipeline: Bottom bar shows ALL tasks flowing through the system, regardless of who requested them.
  • Communication: Profiles communicate via shared filesystem (/opt/data/workspace/tasks/), not separate gateways.
  • One Gateway: Only the default profile (Orchestrator) runs a gateway process. All other profiles are gateway-free.
