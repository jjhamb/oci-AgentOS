# Phase 2 Checklist: Four Persistent Agents (Prompts 3–4)

## After Prompt 3 — Create Four Persistent Agents
- [ ] Analyst created with full system prompt and special rules
- [ ] Writer created with full system prompt and special rules
- [ ] Marketer created with full system prompt and special rules
- [ ] Coder created with full system prompt and special rules
- [ ] All 4 are personas within the SINGLE default profile (not separate profiles)
- [ ] Each agent has its own workspace directory
- [ ] Each agent has its own memory scope
- [ ] Each agent has its own skill definitions

## After Prompt 4 — Memory & Isolated Workspaces
- [ ] Analyst memory: research topics, sources, past findings, preferred news outlets
- [ ] Writer memory: writing style, past topics, tone guidelines, target keywords
- [ ] Marketer memory: goals, strategies, monetization ideas, campaign history, brand voice
- [ ] Coder memory: tech stack, past code decisions, preferred libraries, project structure
- [ ] Each agent has a unique identity (name, role, personality consistent)
- [ ] Each agent has an isolated workspace folder
- [ ] Role boundaries set (agents redirect out-of-scope tasks)
- [ ] Session continuity enabled (agents remember past conversations)
