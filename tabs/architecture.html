Operating Rules

  • Single Profile: Only default exists. Orchestrator routes role-tagged tasks internally via kanban — no separate profiles.
  • Role Tags: Analysts/Writer/Marketer/Coder = [ROLE] prefix in kanban title, assignee=default. Infra workers tagged [INFRA].
  • Shared Kanban DB: All tasks flow through one SQLite DB (~/.hermes/kanban.db). No filesystem channels, no separate gateways.
  • One Gateway: Only default runs a Hermes gateway. Dispatcher polls every 60s, picks tasks with valid assignee.
  • Infra: Manages 5 workers (Executor, Sentinel, Web, Publisher, Reviewer). Reports TO Orchestrator — not a peer.
  • No Duplicates: Each specialist is ONE instance. Infra requests through Orchestrator — never spawns independently.
  • Communication: Snapshot API (/api/snapshot) + kanban API (/api/kanban) = single source of truth for all dashboard data.
